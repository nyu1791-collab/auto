# 刹那 (SETSUNA) — Just-Dodge Duel

1対1のリアルタイム **3D 対戦ゲーム**。円形のアリーナで両者は常に相手をロックオンし、
移動は「前後(接近/後退)」と「左右(サイドステップ)」で行います。

コアは **「ジャスト回避(Just Dodge)」** と **「サイドステップ」** —
攻撃は必ず回避可能で、攻撃の発生直前に反応した精密な回避だけが「ダメージ無効 + 反撃のチャンス」という報酬を得られます。
攻撃には扇形の判定があるため、間合い内でも真横に避ければ空振りさせることができます。
完璧にプレイすれば一切ダメージを受けない、技量天井の高い対戦ゲームです。

設計の詳細は [DESIGN.md](./DESIGN.md) を参照してください。

## セットアップ

```bash
npm install
```

## 開発サーバ起動

```bash
npm run dev
```

ブラウザでローカルサーバを開くとゲームが起動します。デフォルトは **CPU 対戦モード**で、
起動直後から 1 人でプレイできます。

## 操作方法

移動はすべて**ロックオン基準の相対方向**(自動的に相手を向いた状態での前後・左右)です。

|        | 前後(接近/後退) | 左右(サイドステップ) | 回避  | 弱攻撃 | 強攻撃 |
| ------ | ---------------- | ---------------------- | ----- | ------ | ------ |
| P1(青) | W / S            | A / D                   | Shift | F      | G      |
| P2(赤) | ↑ / ↓            | ← / →                   | /     | K      | L      |

- **C**: 「VS CPU」⇄「VS PLAYER(ローカル2P)」の対戦モード切替(デフォルトは VS CPU)
- **V**: CPU の難易度切替(EASY → NORMAL → HARD を循環、デフォルトは NORMAL)
- **M**: ミュート切替(効果音 ON/OFF)
- **Enter** または **Space**: 試合終了(MATCH OVER)後に押すと新しい試合を開始(リスタート)

## スマートフォン / タッチ操作

タッチ対応端末(`pointer: coarse` または `ontouchstart` を検出)では、画面上に
操作 UI が自動的に表示されます。**画面左半分 = バーチャルアナログスティック(移動)、
右半分 = アクションボタン(回避/弱/強)** というシンプルな2分割レイアウトです。

- **P1 レイヤー**(画面下、常時表示): 左にアナログスティック(ドラッグで前後・
  左右=サイドステップを入力)、右に弱・強・回避ボタン(回避は強調表示)。
- **P2 レイヤー**: 「VS PLAYER」(2P対戦)モードのときのみ、画面上側に
  180° 反転した配置で表示。タブレットを横向きに置いて2人で対面プレイする想定です。
- **上部メニュー行**: 対戦切替(C)・難易度切替(V)・ミュート(M)・リスタート(Enter)の
  各ボタンを常設。
- 各操作は Pointer Events によるマルチタッチ対応で、例えば「スティックを操作しながら
  回避をタップ」といった同時操作が可能です。

画面が縦向きの場合は回転を促す案内が表示されます(横向きでのプレイを推奨)。

## 3D アリーナ・カメラ

戦場は円形の 3D アリーナで、両者は常に自動で相手の方を向きます(ロックオン)。
カメラは両者の中間点を追従し、距離に応じてズームを調整します。攻撃の発生中は
攻撃方向と判定範囲を示す扇形のテレグラフが地面に表示されます。

## 音声・視覚効果

- **`AudioEngine`**(`src/audio/audio.ts`): Web Audio API でその場合成する効果音
  (攻撃の振り、ヒット、ジャスト回避、回避、KO、ラウンド開始/終了)。音声ファイルは使用しません。
- **`ParticleSystem`**(`src/render/particles.ts`): Three.js の `THREE.Points` による
  3D パーティクル。ヒット時の火花、ジャスト回避時の放射状バースト、回避時の砂塵などを表現します。
- **`Renderer`**(`src/render/renderer.ts`): Three.js でアリーナの床・グリッド、
  キャラクターのカプセル体型 + 向きを示すバイザー、攻撃中・被スタン中のグロー、
  回避中の残像、攻撃の扇形テレグラフ、画面シェイク・フラッシュなどを描画します。
- **`Hud`**(`src/render/hud.ts`): WebGL キャンバスに重ねた HTML オーバーレイで
  HP/スタミナバーの滑らかな減少 + チップダメージ表示、WINS ピップ、
  READY/FIGHT! やラウンド/マッチ結果、「JUST!」ポップなどを表示します。

これらはすべて `src/engine/**`(純粋・決定論的なゲームロジック)の**外側**に存在し、
`npm run sim` やエンジンのユニットテストには一切影響しません。

### ラウンド進行

各ラウンド開始前に「READY... → FIGHT!」のカウントダウンが入り、ラウンド終了後は
結果表示のまま少し止まってから次のラウンド(または試合終了)に進みます。
3 本勝負(先取 2 本)で試合の勝者が決まります。
