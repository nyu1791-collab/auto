# 刹那 (SETSUNA) — Just-Dodge Duel

1対1のリアルタイム対戦ゲーム。コアは **「ジャスト回避(Just Dodge)」** —
攻撃は必ず回避可能で、攻撃の発生直前に反応した精密な回避だけが「ダメージ無効 + 反撃のチャンス」という報酬を得られる。
完璧にプレイすれば一切ダメージを受けない、技量天井の高い対戦ゲームです。

設計の詳細は [DESIGN.md](./DESIGN.md) を参照してください。

## セットアップ

```bash
npm install
```

## 開発サーバ起動

```bash
npm run dev
```

ブラウザでローカルサーバを開くとゲームが起動します。デフォルトは **CPU 対戦モード**で、
起動直後から 1 人でプレイできます。

## テスト

```bash
npm test
```

## バランスシミュレーション

ヘッドレスでスクリプト AI 同士を対戦させ、勝率・被ダメージ・ジャスト回避率などを確認します。

## 操作方法

|            | 移動  | 回避 | ジャンプ | 弱攻撃 | 強攻撃 |
| ---------- | ----- | ---- | -------- | ------ | ------ |
| P1(左・青) | A / D | W    | Space    | F      | G      |
| P2(右・赤) | ← / → | ↑    | Shift    | K      | L      |

ジャンプは空中でもう一度入力すると二段ジャンプになります(ジャンプで攻撃を飛び越えて
回避することも可能)。

- **C**: 「VS CPU」⇄「VS PLAYER(ローカル2P)」の対戦モード切替(デフォルトは VS CPU)
- **V**: CPU の難易度切替(EASY → NORMAL → HARD を循環、**デフォルトは EASY**)
- **H**: ジャスト回避アシスト(タイミングを教える収束リング)の ON/OFF 切替(デフォルト ON)
- **M**: ミュート切替(効果音 ON/OFF)
- **Enter** または **Space**: 試合終了(MATCH OVER)後に押すと新しい試合を開始(リスタート)

> **やさしさ調整**: ジャスト回避の猶予を約 120ms → 150ms に広げ、初期難易度を EASY に、
> さらに「ジャスト回避アシスト」を標準 ON にしています。攻撃側を囲むリングが金色に光った
> 瞬間に回避を出すとジャスト回避が決まります。慣れてきたら H で消し、V で難易度を上げられます。

## スマートフォン / タッチ操作

タッチ対応端末(`pointer: coarse` または `ontouchstart` を検出)では、キャンバス上に
画面操作 UI が自動的に表示されます。

- **P1 操作クラスタ**(常時表示): 画面左端に移動(◀ / ▶)、画面右端に弱攻撃・強攻撃・回避・
  ジャンプボタン(回避とジャンプは他より大きいボタンで強調表示)。デフォルトの VS CPU
  モードでは画面の全幅を使って操作を左右に大きく分離します。
- **P2 操作クラスタ**: 「VS PLAYER」(2P対戦)モードのときのみ表示。この時は両クラスタが
  画面の左右半分ずつになり、P1 とは反転配置で画面右側に表示されます。
  タブレットを横向きに置いて2人で対面プレイする想定です。
- **上部メニュー行**: 対戦切替(C)・難易度切替(V)・アシスト(H)・ミュート(M)・
  リスタート(Enter)の各ボタンを常設。
- 各ボタンは Pointer Events によるマルチタッチ対応で、例えば「◀ を押しながら回避をタップ」
  といった同時操作が可能です。

画面が縦向きの場合は回転を促す案内が表示されます(横向きでのプレイを推奨)。

## 音声・視覚効果

- **`AudioEngine`**(`src/audio/audio.ts`): Web Audio API でその場合成する効果音
  (攻撃の振り、ヒット、ジャスト回避、回避、ジャンプ、着地、KO、ラウンド開始/終了)。
  音声ファイルは使用しません。
- **`ParticleSystem`**(`src/render/particles.ts`): ヒット時の火花、ジャスト回避時の
  放射状バースト、回避時の砂塵、ジャンプ着地時の砂塵などの演出パーティクル。
- レンダラー(`src/render/renderer.ts`)はグラデーション背景、キャラクターの角丸ボディ・
  向き表示・攻撃時のグロー、回避中の残像、HP バーの滑らかな減少 + チップダメージ表示、
  ラウンド開始/終了画面の演出などを描画します。ジャンプ中はキャラクターが高さに応じて
  上下し、上昇/落下/着地でスクワッシュ&ストレッチ(伸縮)アニメーションが入ります。

これらはすべて `src/engine/**`(純粋・決定論的なゲームロジック)の**外側**に存在し、
`npm run sim` やエンジンのユニットテストには一切影響しません。

### ラウンド進行

各ラウンド開始前に「READY... → FIGHT!」のカウントダウンが入り、ラウンド終了後は
結果表示のまま少し止まってから次のラウンド(または試合終了)に進みます。
3 本勝負(先取 2 本)で試合の勝者が決まります。
